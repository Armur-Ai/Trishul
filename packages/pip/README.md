# trishul

Security Scanner for Vibe-Coded Software — SAST + DAST + exploit simulation + attack path analysis.

## Install

```bash
pip install trishul
# or
pipx install trishul
```

## Usage

```bash
trishul run .          # scan current directory
trishul scan <path>    # scan a specific path
trishul doctor         # check tool availability
```
